\addcontentsline{toc}{section}{Введение}

В отчете представлено описание выполнения лабораторной работы №2 по дисциплине «Теория алгоритмов».

Базовые функции часов~--- отображение и корректировка часов и минут текущего времени. Варианту 43 соответствует код $100102322$. Его разряды задают следующие требования.

\begin{enumerate}[label=\Alph*),leftmargin=*]
	\item Отображение и корректировка секунд.
	\item Дополнительные счетчики времени в разных часовых поясах отсутствуют.
	\item Совместная корректировка десятков и единиц.
	\item Отображение времени в 24-часовом формате.
	\item Постоянно включенная индикация, без режима энергосбережения.
	\item Останов часов при выходе из режима корректировки текущего времени. Запуск часов по нажатию кнопки.
	\item Секундомер с возможностью просмотра текущего времени при продолжающемся отсчете.
	\item Звуковая сигнализация каждые 15 минут длительностью одну секунду.
	\item Будильник с выбором мелодии по номеру и возможностью отключения.
\end{enumerate}
